# Lantern
A cozy RPG-inspired web application for gamifying habit and task tracking through XP, progression, achievements, and customization.

## Project Overview
People struggle to maintain habits because the results of their efforts are delayed, which can make it difficult to stay motivated. Gamification can bridge the gap by providing immediate feedback through XP, progression, and rewards. Lantern will use RPG-inspired progression, achievements, and customization to encourage users to continue working toward their real-world goals. 

## Planned Technology Stack
- Frontend: React, JavaScript, HTML/CSS
- Backend: Java, Spring Boot
- Authentication: Spring Security, JWT, BCrypt
- Database: PostgreSQL
- Unit Testing: JUnit
- API Testing: Postman
- Design: Figma
- Deployment: Render
